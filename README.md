# SQL_Project
# 🏎️ New Wheels SQL Sales Analysis Project

An end-to-end SQL analytics project designed to explore, clean, and extract business insights from the **New Wheels** vehicle sales database. This project maps complex data relationships, writes structured queries to evaluate quarterly performance, and answers critical business questions for stakeholders.

---

## 📂 Repository Contents

* **`new_wheels_project_dumpfile.sql`**: The complete SQL database schema dump containing tables, records, and primary keys.
* **`new_wheels_ER_diagram.pdf`**: Entity-Relationship Diagram mapping out the database structure and relational keys.
* **`new_wheels_sales_data_dictionary.txt`**: Detailed descriptions of the database columns, data types, and business logic definitions.
* **`new_wheels_project_questions.txt`**: The core business problems and analytical questions tackled in this project.
* **`submission_template_coded_project.pdf`**: Completed project report showcasing final code syntax and calculated insights.

---

## 🛠️ Database Tech Stack & Skills

* **Language:** Structured Query Language (SQL)
* **Core Concepts:** Entity-Relationship Modeling, Joins (Inner, Left, Right), Aggregations (`COUNT`, `SUM`, `AVG`), Common Table Expressions (CTEs), Subqueries, and Data Sorting/Filtering (`GROUP BY`, `HAVING`).
